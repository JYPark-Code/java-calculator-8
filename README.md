# java-calculator-precourse

## 구현 기능 목록

- **빈 문자열 입력 시**  
  → `0` 반환

- **기본 구분자 지원**  
  → 쉼표(`,`), 콜론(`:`)으로 구분된 숫자 합산  
  예: `"1,2:3"` → `6`

- **커스텀 구분자 지원**  
  → `"//{구분자}\n{숫자들}"` 형식 인식  
  예: `"//;\n1;2;3"` → `6`

- **잘못된 입력 처리**
    - 구분자와 숫자 개수 불일치 (`"1,2,"`, `"1,,2"`) → 예외 발생
    - 숫자가 아닌 문자가 포함된 경우 (`"1,a,3"`) → 예외 발생
    - 공백 포함 (`"1 2,3"`) → 예외 발생
    - 음수 입력 (`"-1,2"`) → 예외 발생
    - `int` 범위를 초과하는 값 (`"2147483648"`) → 예외 발생
    - 합계가 `int` 범위를 초과하는 경우 → 예외 발생

- **예외 처리 통일**
  → 모든 오류는 `IllegalArgumentException`으로 처리하며, 명확한 메시지 제공

- **오버플로 방지**
  → `Math.addExact()` 사용으로 합계 계산 시 `int` 범위 초과 감지

- **정규식 기반 커스텀 구분자 파싱**
    - `Pattern` / `Matcher` 사용
    - 구분자 추출: `group(1)`
    - 숫자 문자열 추출: `group(2)`
    - `Pattern.quote()` 로 특수문자 구분자 안전 처리

- **안정적 입력 검증**
    - `Character.isDigit()`으로 숫자만 허용
    - `Character.isWhitespace()`로 공백 검출
    - 빈 토큰(`""`) 검사로 구분자 오류 방지

- **사용자 인터페이스**
    - `Scanner`로 문자열 입력 받음
    - 정상 결과 또는 예외 메시지 출력

---

## 입력 / 출력 예시

| 입력 | 출력 |
|------|------|
| `""` | `0` |
| `"1,2:3"` | `6` |
| `"//;\n1;2;3"` | `6` |
| `"1,,2"` | `예외 발생` |
| `"-1,2"` | `예외 발생` |
| `"2147483647,1"` | `예외 발생` |
